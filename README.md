# 云琢紫砂 · 数字工坊

纯前端静态站点：带动画的品牌主页，以及可交互的紫砂壶 Web3D 定制预览。不依赖 Python、SQLite 或任何后端接口。

## 启动

在本目录用任意静态服务器打开即可，例如：

```bash
python3 -m http.server 8000
```

浏览器访问 <http://127.0.0.1:8000/>。

因页面使用 ES modules 与 Three.js，请通过本地 HTTP 服务访问，不要直接双击打开 HTML。

## 页面

- `/`：品牌主页（dev 分支的动画门户）
- `/preview/`：紫砂壶定制预览（main 分支的 Web3D 工坊）

主页上的入口全部跳转到 `/preview/`。预览页可换器型、泥色、纹样、彩绘和容量，数据只留在浏览器本地。
